# ⚽ BEST XI - Football Formation

선수 이름과 주 포지션/가능 포지션을 저장하고, 포메이션을 선택하면 베스트 일레븐을 자동 구성하는 정적 웹앱입니다.

## 기능
- 선수 등록 및 삭제
- 주 포지션 + 복수 가능 포지션 저장
- 브라우저 localStorage 자동 저장
- 4-3-3 / 4-2-3-1 / 4-4-2 / 4-1-4-1 / 3-5-2 / 3-4-3 / 5-3-2
- 포지션 적합도 기반 자동 베스트 XI
- 자동 구성 후 선수 클릭으로 교체
- 선수 드래그로 위치 이동
- 모바일 반응형 UI

## GitHub Pages 배포
1. 이 폴더의 파일을 GitHub repository에 업로드합니다.
2. GitHub → Settings → Pages
3. Source: Deploy from a branch
4. Branch: main / root
5. Save

서버 없이 작동하며 선수 데이터는 사용하는 브라우저의 localStorage에 저장됩니다.
